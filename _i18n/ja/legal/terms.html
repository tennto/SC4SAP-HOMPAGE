1.本契約

本規約は、SC4SAP コンソール、そのバックエンド、Skill、ドキュメント、および当社が同じ場所で提供するその他すべてのもの(以下、総称して本サービス)の利用に関して、お客様と 에스에이치솔루션즈 との間で締結される契約です。アカウントを作成すること、SAP システムを接続すること、または Session を一度でも実行することは、本規約への同意を意味します。

雇用主または顧客を代理して同意する場合、お客様はその組織を拘束する権限を有することを確認したものとします。その時点から、本規約におけるお客様とはその組織を指し、同意をクリックした本人はその組織のユーザーの一人となります。

本契約の一部を構成する文書

プライバシーポリシー、お客様が申し込んだプランおよび料金ページ、ならびに当社がお客様と書面で締結した注文書またはデータ処理契約は、本契約の一部です。これらが矛盾する場合は、より具体的な文書が優先します。署名済みの注文書が最初、次にデータ処理契約、次に本規約、最後にその他すべての文書の順です。

2.定義

  • 接続システム — お客様が接続プロファイルを通じて本サービスに登録した SAP システムをいい、その ABAP リポジトリ、データディクショナリ、ランタイムおよびトランスポートオーガナイザーを含みます。
  • 接続プロファイル — 本サービスが接続システムに到達できるようにするために保存されたホスト、クライアント、認証情報およびティアをいいます。
  • ティア — プロファイルに付与されるラベル(開発、品質保証、本番、またはお客様が定めるこれに相当する区分)をいい、Session が当該システムに対してどの種類のツールを使用できるかを決定します。
  • Skill — 本サービスが接続システムに対して実行する名前付きのワークフローをいい、プログラムの分析、症状の追跡、パッケージのインベントリ作成、仕様書の作成、リポジトリオブジェクトの作成、トランスポートのリリース、およびカタログに含まれるその他の項目を指します。
  • Session — アシスタントとの一回の会話をいい、そのプロンプト、ツール呼び出し、お客様が許可または拒否した承認、およびその結果として生成される会話記録を含みます。
  • お客様のコンテンツ — お客様が提供するすべてのもの、および本サービスがお客様の指示に基づいて読み取るすべてのものをいい、プロンプト、アップロードされたファイルと参考ノート、ABAP ソース、ディクショナリのメタデータ、設定値、トランスポートの内容、および Session が生成する成果物を指します。
  • アウトプット — お客様のコンテンツのうちモデルが生成した部分をいい、回答、仕様書、分析、生成されたコードを指します。
  • モデルプロバイダー — Anthropic をいい、本サービスは Session を実行するためにその API を呼び出します。
  • ガードレール — ツール呼び出しを除外し、ブロックし、または承認を要求する第8条の管理機能のいずれかをいいます。

6.モデルの利用と第三者サービス

モデルの利用は当社のアカウントで行われます

本サービスは、当社のモデルプロバイダーアカウントで Session を実行します。お客様が API キーを登録することはなく、モデルプロバイダーに直接利用料を支払うこともありません。モデルの利用料は、別途定めるところにより、お客様のプランの込み利用量とクレジットから差し引かれます。モデルプロバイダーの利用ポリシーが、本規約に加えてそのトラフィックに適用され、モデルプロバイダー側の変更は本サービスができることを変えることがあります。

利用量は作業の大きさによって変わります

トークンのコストは、Session が読み取らなければならないソースとメタデータの量に比例します。大きなパッケージに対する広範な質問は、狭い質問の何倍もの利用量を使うことがあり、パッケージ全体のインベントリを作成する Skill は本質的に利用量が多くなります。込み利用量とクレジットを使い切ると、新しい作業は開始できません。

コンソールに表示されるコストの数値

Session ごとに表示されるコストは、当該 Session が報告した内容を当社がモデルプロバイダーの標準単価で集計したものです。込み利用量とクレジットの差し引きは、この集計に基づいて行います。

モデルの選択

Skill がどのモデルで実行されるかは当社が選択し、品質、コスト、可用性、またはモデルの提供終了を理由にその選択を変更することがあります。その結果、アウトプットが変わることがあります。変更が Skill に期待できる内容を実質的に変える場合、当社はリリースノートにその旨を記載します。

ネットワークの外部に送信することが許可されていないデータに本サービスを向けないでください。 第8条のガードレールは、大量の個人データや金融データがシステムの外に出るリスクを低減しますが、これはセーフティネットであり、コンプライアンスプログラムではありません。ガードレールはお客様に代わってデータを分類することができず、お客様のカスタムテーブルのどれが個人データを保持しているかを知らず、お客様自身によるレビューの代わりにはなりません。

当社は、お客様が作業を再開できるように、また承認の監査記録が存在するように、お客様のアカウント情報、接続プロファイル、および会話記録を含む Session を保存します。プロファイル内の秘密情報は保存時に暗号化され、保存された後にブラウザに再表示されることはありません。

保持と削除

お客様はいつでも Session またはプロファイルを削除することができ、アカウントを削除すると、当社が保持を義務付けられている記録を除き、プライバシーポリシーに定めるスケジュールに従って両方が削除されます。バックアップは独自のサイクルで期限切れとなるため、削除はすべての場所で即時に行われるわけではありません。

当社がお客様に代わって個人データを取り扱う場合、当社はプライバシーポリシーおよび当事者間のデータ処理契約に記載のとおり、お客様の指示に基づく処理者としてこれを取り扱います。Session が個人データを適法に扱うことができるかどうかを判断することは、当社ではなく管理者であるお客様の責任です。

8.ガードレールと承認

本サービスは、Session ができることを三つの層で制約しており、各層は意図的に異なる方向に失敗するよう設計されています。

第一層 — ティアによって除外されるツール

接続システムを変更するツールは、書き込みが許可されていないティアに対して実行される Session から完全に取り除かれます。モデルは見えないものを呼び出すことができないため、この層は巧妙に書かれたプロンプトによって回避することができません。

第二層 — ブロックリスト

常設のブロックリストに掲載されたテーブル — 銀行、給与およびこれに準ずるデータを含みます — に対する行の抽出は、全面的にブロックされます。この層は、要求がお客様に届く前に動作します。この層が作動した場合、承認すべきものはなく、他のどこで与えられた承認もこれを覆すことはできません。

第三層 — 人間による承認

最初の二つの層を通過した機微な呼び出しは、停止してお客様に確認を求めます。お客様が回答するまで何も実行されません。回答されないまま放置された要求はタイムアウト後に自動的に拒否され、ブラウザを閉じることは承認ではなく拒否として扱われます。

承認は指示です

呼び出しを許可することは、お客様の認証情報でお客様のシステムに対してその呼び出しを行うよう本サービスに指示することであり、お客様はその結果を受け入れることになります。許可する前に呼び出しの内容をお読みください — 要求画面がツールとその正確な入力を表示するのはそのためです。呼び出しが実行された後は、承認を取り消すことはできません。

ガードレールを無効化しないでください

お客様は、以下を含め、いかなるガードレールも回避しようと試みないものとします。

  • ブロックリストを回避するために、プロンプトを言い換えたり、要求を断片に分割したりすること。
  • ティアが除外するデータに到達するために、SAP ユーザーの権限を拡大すること。
  • 書き込みツールを解放するために、プロファイルのティアを誤って表示すること。
  • 本サービスのツールを迂回する経路で接続システムに到達すること。

ガードレールが約束しないこと

ガードレールはツールを制約するものであり、お客様のデータを監査するものではありません。ソースコードの中にある値はソースコードの一部であるため、ガードレールは、お客様が本サービスに読み取らせたプログラムに機微な値が一切現れないことを保証することはできません。ガードレールはお客様の管理策のすべてではなく、その一つとしてお考えください。

9.変更、トランスポート、そして非本番環境を先に

レビュー、承認、テストおよびリリースは、引き続きお客様の責任です。本サービスはお客様のプロセスを見ることができず、お客様のリリーススケジュールを知らず、何を移送してよいかを判断しません。本サービスが生成するいかなるものも、お客様の組織が求める承認の代わりにはなりません。

非本番環境を先に

生成された作業は開発システムまたはサンドボックスシステムに対して実行し、差分をレビューし、次の段階へ進める前にテストしてください。変更を容易に元に戻せない場合は、バックアップまたはスナップショットを取得してください。何をいつリリースするかはお客様が決定し、お客様がリリースした変更が下流で引き起こす結果について、当社は責任を負いません。ただし、その結果が当社の故意または過失により生じた場合はこの限りではありません。

10.アウトプットはドラフトであり、助言ではありません

誤っている可能性があります

本サービスは言語モデルの上に構築されており、そのアウトプットは — お客様自身のコードに関するものであっても — 誤っていたり、不完全であったり、自信を持って間違っていたりすることがあります。お客様のシステムに存在しないテーブルを引用したり、プログラムにはない動作を説明したり、コンパイルは通るが誤った動作をする ABAP を生成したりすることがあります。仕様書、分析、症状の追跡および生成されたコードは、有能なレビュー担当者のためのドラフトであり、納品物ではありません。

専門的な助言ではありません

本サービスが生成するいかなるものも、法務、税務、監査、セキュリティ、会計またはその他の専門的な助言ではなく、お客様の利用によっていかなる助言関係も生じません。重要なシステムに到達するすべてのものについて、資格を有する人間が責任を負うようにしてください。

お客様に固有のものではありません

類似のプロンプトは、異なる顧客に対して類似のアウトプットを生成します。当社はアウトプットが独創的であるとも、お客様に固有であるとも主張せず、お客様もその利用方法を決める際にそうであると想定すべきではありません。
