The AI workspace
that understands SAP

SC4SAP (Super-Claude for SAP) is an AI that connects to your SAP system and reads its code, configuration and business flows. Analysis, documentation and development all happen in one place.

What SC4SAP is

Most SAP work is reading the system. To understand a single program, you trace the source line by line, follow table relationships, ask the person in charge and wait for an answer. That is why one specification can take days.

With SC4SAP, Claude connects directly to your system through ADT and does this work for you. It answers questions by querying real tables and source, produces specifications, manuals and process documents with business skills, and builds the relationships it analyzes into a knowledge graph that it reuses in later answers.

Two ways to use it

Open source

SC4SAP Plugin

Claude Code CLI plug-in

Add it from the marketplace to a Claude Code session in your terminal or VS Code. Run the setup wizard /sc4sap:setup once and it installs the MCP server for the SAP connection for you.

  • Analyze, generate and diagnose with skill commands
  • A single developer can start right away
  • Source published on GitHub
Install guide (CLI) GitHub
PoC · closed test

SC4SAP Web

A web workspace for teams

Use it in the browser with nothing to install. Connect your system once, and chat, business skills, monitoring and the knowledge graph all come together on one screen.

  • Collaborate in chat with an AI that knows your system
  • A knowledge graph that grows with every analysis, with two-way Obsidian sync
  • VS Code · Obsidian · Notion integrations
  • Standard and Eco modes sized to the job

What it can do

We packaged the work that repeats across real implementations and operations into skills. The plug-in and the web workspace use the same skills.

  • Ask a consultantModule questions answered with values from your system
  • Code analysisFindings and fix suggestions by review perspective
  • Symptom analysisLikely causes from dumps and errors
  • CBO inventoryReusable assets and gaps across modules
  • Program comparisonCompare 2 to 5 programs that have diverged
  • Program → specFunctional and technical specs with screen mockups
  • Program → manualUser manuals for business users
  • Module → processBusiness flows drawn from the T-codes actually in use
  • Config → documentActual configuration values documented in IMG order
  • Interface mapping specField mappings and conversion rules
  • Program generationFrom requirements to an ABAP program
  • Object generationCreate and activate tables and classes
  • PDF → SmartFormGenerated straight from a print-form PDF
  • SmartForm previewThe expected output as an image
  • Project dashboardMilestones, WBS and progress on one page
  • Authorization matrixRole, T-code and SoD authorization documents
  • SAP diagnosticsChecks the plug-in, MCP and SAP connection
  • Eco modeThe same deliverables at a lower cost
