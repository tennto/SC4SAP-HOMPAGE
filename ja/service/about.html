About

SAP を理解する
AI ワークスペース

SC4SAP（Super-Claude for SAP）は、お使いの SAP システムに接続し、コードや設定、業務フローまで読み解く AI です。分析からドキュメント作成、開発までを同じ場所で進められます。

SC4SAP とは

SAP の業務の大半は、システムを読む作業です。プログラム 1 本を理解するためにソースを 1 行ずつ追い、テーブルの関係をたどり、担当者に質問して回答を待ちます。仕様書 1 件に何日もかかるのはそのためです。

SC4SAP では、ADT でシステムに直接接続した Claude がこの作業を代わりに行います。質問には実際のテーブルやソースを照会して答え、業務スキルで仕様書・マニュアル・プロセス文書を作成し、分析した関係はナレッジグラフに蓄積して次の回答に活かします。

2 つの使い方があります

オープンソース

SC4SAP Plugin

Claude Code CLI プラグイン

ターミナルや VS Code の Claude Code セッションにマーケットプレイスから追加して使います。設定ウィザード /sc4sap:setup を一度実行すれば、SAP 接続用の MCP サーバーまで自動でインストールされます。

  • スキルコマンドで分析・生成・診断
  • 開発者 1 人ですぐに始められます
  • GitHub で公開されたソース
インストールガイド（CLI） GitHub
PoC · クローズドテスト

SC4SAP Web

チームのための Web ワークスペース

インストール不要で、ブラウザから使えます。システムを一度接続すれば、チャット、業務スキル、モニタリング、ナレッジグラフが 1 つの画面でつながります。

  • システムを理解した AI とチャットで協働
  • 分析結果が蓄積されるナレッジグラフ、Obsidian との双方向同期
  • VS Code · Obsidian · Notion 連携
  • 作業規模に合わせた標準モード・エコモード

できること

実際の導入や運用で繰り返される作業をスキルとしてまとめました。プラグインと Web は同じスキルを使います。

  • コンサルタントに質問システムの値で答えるモジュールの質問
  • コード分析レビュー観点ごとの指摘事項と修正提案
  • 症状分析ダンプやエラーから原因の候補を特定
  • CBO インベントリ再利用できる資産とモジュール間のギャップ
  • プログラム比較分岐したプログラム 2〜5 本を比較
  • プログラム → 仕様書機能・技術仕様書と画面モックアップ
  • プログラム → マニュアル業務部門向けユーザーマニュアル
  • モジュール → プロセス実際に使われている T-code で描く業務フロー
  • 設定 → 文書実際の設定値を IMG の順序で文書化
  • インターフェースマッピング定義書フィールドマッピングと変換ルール
  • プログラム生成要件から ABAP プログラムまで
  • オブジェクト生成テーブル・クラスの作成と有効化
  • PDF → SmartForm印刷様式の PDF から直接生成
  • SmartForm プレビュー想定される出力を画像で確認
  • プロジェクトダッシュボードマイルストーン・WBS・実績を 1 ページに
  • 権限マトリクスロール・T-code・SoD の権限文書
  • SAP 診断プラグイン・MCP・SAP 接続のチェック
  • エコモード同じ成果物をより低いコストで
