SC4SAP プロジェクトへのスポンサーシップ

SC4SAP は、オープンソースのプラグインと Web ワークスペースで SAP 業務のあり方を変えつつあります。この取り組みを一緒に育てていただけるスポンサーとパートナーを探しています。

参加いただく 2 つの方法

Sponsor

スポンサー

プロジェクトの開発と運営を支援します

オープンソースプラグインの保守、新しいスキルの開発、Web ワークスペースの正式リリースにお力添えください。スポンサーの皆さまには、以下の特典をご用意しています。

スポンサーについて問い合わせる
Co-work

共同作業

一緒につくり、一緒に検証します

SAP コンサルティング会社・SIer・ユーザー企業とスキルを一緒につくり、実際のプロジェクトで検証します。業種やモジュールに合わせた機能を共同で設計できます。

Co-work について問い合わせる

スポンサーへの特典

  • 新機能の先行利用新しいスキルや Web ワークスペースの機能を、正式公開前にいち早くお試しいただけます
  • ロードマップへの意見反映必要な機能をご提案いただければ、開発の優先順位を決める際に反映します
  • 専用サポートチャネルインストール・接続・運用のお問い合わせを個別に受け付けるチャネルを開設します
  • 導入・トレーニングセッション社内チーム向けの導入説明会と利用トレーニングを実施します
  • PoC の優先支援貴社の環境で Web ワークスペースの PoC を優先的に構築します
  • スポンサー表記ご希望に応じて、ホームページと GitHub リポジトリにスポンサーとして掲載します

Co-work で一緒にできること

カスタムスキル開発
貴社の業務手順や成果物の様式に合わせたスキルを、一緒に設計・開発します。
業種・モジュール特化
製造・流通・金融など業種別のプロセスや特定のモジュールに合わせた分析とドキュメント作成を、一緒に磨き上げます。
共同 PoC
実際のプロジェクトの一部を SC4SAP で進め、効果と限界を一緒に測定します。
オープンソースへの貢献
プラグインのリポジトリに Issue やプルリクエストで直接参加できます。

進め方

  1. 01

    メールでお問い合わせ

    スポンサーと Co-work のどちらをご希望か、また関心のある分野をお知らせください。

  2. 02

    初回ミーティング

    貴社の状況やご期待をお伺いし、SC4SAP がお役に立てる部分を一緒に整理します。

  3. 03

    範囲と条件の合意

    提供内容、期間、進め方を決め、必要に応じて契約としてまとめます。

  4. 04

    スタート

    担当者を決め、定期的に進捗を共有します。

一緒につくっていただける方をお待ちしています

メールに会社名、ご担当者の連絡先、ご希望の形（スポンサー・Co-work）、関心のある分野をご記入いただければ、早急にご返信します。
