GETTING STARTED

01

설치

Claude Code에 커스텀 마켓플레이스를 추가하고 플러그인을 설치합니다

/plugin install sc4sap
02

연결

SAP 버전과 업종, 국가를 한 번 답하면 MCP 서버와 권한 훅까지 등록됩니다

/sc4sap:setup
