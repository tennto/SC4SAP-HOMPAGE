작업 중
요약최종 결과만 표시

ZMMR00020은 구매오더(PO) 항목에 대한 변경 이력을 조회하는 감사용 ALV 리포트입니다. 자체 변경이력 테이블 ZMMT00120을 기준으로 EKKO와 조인해 공급업체 코드를 얻고, LFA1에서 공급업체명을 보강해 변경 전/후 값 · 변경 사유 · 변경자 · 변경일시를 도킹 컨테이너 ALV로 보여줍니다.

특이사항: 표준 CDHDR/CDPOS가 아닌 커스텀 테이블을 변경이력 원천으로 쓰고 있고, 구매문서/공급업체 조회에 대한 AUTHORITY-CHECK가 전혀 없어 운영 반입 전 보안 검토가 필요합니다.

기능/기술 명세서: ZMMR00020

한 줄 목적

구매오더(PO) 항목에 대한 변경 이력(필드별 변경 전/후 값, 변경 사유, 변경자/변경일시)을 조회하여 감사(Audit) 목적으로 조회하는 리포트

오브젝트 유형ABAP Report (Executable Program), Include 구조 (T/S/A/O/I/F)
패키지ZMMPAEK
아키타입선택화면 → 조회 → ALV Grid(도킹 컨테이너) 표시형 리포트

1. Business context

본 프로그램은 구매오더(Purchase Order) 데이터에 대한 변경 이력을 추적하는 감사용 리포트이다. 구매 담당자, 내부통제/감사 담당자가 특정 PO 또는 특정 기간에 어떤 필드가 누구에 의해 언제, 어떤 사유로 변경되었는지를 확인할 수 있도록 지원한다.

2. Data model

TableAccessKey fieldsNotes
ZMMT00120REBELN, EBELP, SEQ_NO커스텀 PO 변경이력 테이블. 변경 전후 값, 사유, 변경자, 변경시각 보유
EKKOREBELNPO 헤더에서 공급업체(LIFNR) 획득 목적으로만 조인
LFA1RLIFNR공급업체명(NAME1) 조회, 루프 내 건별 SELECT SINGLE

3. Inputs & screens

FieldTypeRequiredDescription

P_FIELDPARAMETERS (CHAR 30)선택변경 필드명 패턴 (와일드카드 비교)

4. Main logic

  1. 사용자가 선택화면에서 PO번호, PO항목, 변경일자, 필드명 조건을 입력한다.
  2. START-OF-SELECTION에서 데이터 조회 FORM을 호출한다.
  3. ZMMT00120과 EKKO를 PO번호로 INNER JOIN하여 변경이력을 조회한다.
01선택화면ZMMR00020S
02데이터 조회ZMMT00120
03공급업체 결합LFA1
04ALV 표시화면 0100
